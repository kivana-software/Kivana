# Kivana (Basic)

The basic, local-only desktop app for Kivana built with Tauri + React + TypeScript + Vite.

- No login, no cloud sync
- Data is stored locally on your device

License: MIT (see LICENSE).

## Dev

```bash
npm install
npm run tauri:dev
```

## Build

```bash
npm run tauri:build
```

## Scripts

- `npm run dev`: Vite web dev server (used by Tauri dev).
- `npm run tauri:dev`: Start desktop app in dev mode.
- `npm run build`: Typecheck + Vite production build.
- `npm run tauri:build`: Build desktop bundles/installers.
- `npm run lint`: ESLint.
